できること

使うのは、自分の Claude Code

字幕は外部の要約サービスを通らず、自分のマシンの Claude Code に直接届きます。

API キーはいらない

いつもログインしている Claude Code をそのまま呼び出します。新しく契約するものはありません。

時刻から、その場面へ

要約の見出しや答えに付く [12:34] を押すと、動画がその位置から再生されます。

要約の指示は自由に

「3 行で要点、次に見出しごと…」といった指示文は、設定画面で好きなように書き換えられます。

作業フォルダを選べる

選んだフォルダの CLAUDE.md を読み込んで答えます。プロジェクトに合わせた視点で要約できます。

別のマシンにもつなげる

Tailscale を使えば、Mac のブラウザから家の Raspberry Pi の Claude Code を呼べます。接続先はいくつでも登録できます。

Claude に道具は渡さない

Claude Code はファイル操作やコマンド実行ができない状態で動きます。中継はトークンで守られます。

はじめかた

3 ステップで準備完了

Claude Code が動くマシンに小さな中継（ブリッジ）を入れて、ブラウザに拡張を読み込みます。

ブリッジを入れる

Claude Code が動くマシンで bridge/install.sh を実行。別のマシンのブラウザから使うなら --tailscale を付けます。最後にトークンが表示されます。

拡張を読み込む

chrome://extensions（Brave は brave://extensions）で「デベロッパーモード」を ON にし、extension フォルダを読み込みます。

接続先を登録

youyakun のアイコンから設定画面を開き、ブリッジの URL とトークンを入れて「接続を確かめる」→「保存」。

よくある質問

気になるところ

Claude Code がないと使えませんか？

はい。youyakun は、自分のマシンで動いている Claude Code に字幕を渡す拡張です。字幕のコピーだけなら、Claude Code なしでも使えます。

API キーや追加の料金は必要ですか？

API キーは使いません。いつも使っている Claude Code をそのまま呼び出すので、使った分はその Claude Code の利用分になります。

字幕のない動画でも使えますか？

使えません。YouTube の字幕（自動生成を含む）を読んでいるため、字幕がない動画は要約できません。

ブリッジとは何ですか？

ブラウザから届いた字幕と質問を Claude Code に中継する小さなプログラムです。Python の標準ライブラリだけで書かれていて、トークンを知っている相手からの依頼しか受け付けません。

Claude にファイルを読まれたり、コマンドを実行されたりしませんか？

しません。ブリッジは Claude Code に道具を一切渡さずに動かします（--tools ""）。作業フォルダで変わるのは、読み込まれる CLAUDE.md と会話の保存先だけです。

会話の続きをターミナルでやりたい。

パネルの「ターミナルで続けるコマンドをコピー」で、同じ会話を Claude Code の CLI から続けられます。

アンインストールするには？

拡張は chrome://extensions から削除します。ブリッジは systemctl --user disable --now youyakun-bridge で止められます。
